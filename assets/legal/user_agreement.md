## 一、服务说明

### 1.1 产品定位

「MoodDiary 心情日记」是一款**面向日常情绪记录与倾诉陪伴的个人记录工具**。本 App 定位于 **personal tracking / journaling**,**不提供医疗建议、诊断、治疗或临床决策支持**。

App 类别 (iOS LSApplicationCategoryType): **`lifestyle`** (个人记录工具,非医疗类目)

### 1.2 核心功能

| 模块 | 功能 | 用途 |
|---|---|---|
| **情绪日记** | 4 维评分(心情/能量/睡眠/焦虑) · 影响因素标签 · 状态短语 · CBT 3/5/7 栏思维记录 · 语音录入 / STT | 自我观察 + 趋势分析 |
| **树洞倾诉** | 文字 · 录音 · 标签(归属学习/工作/情感/身心健康 3 大类 8 子标签) | 私密倾诉 |
| **自我测评** | 10 个量表(ISI / PSS / WHODAS / DSM-5 Level2 × 4 / ASRM) | 自我观察工具 |
| **自我照护 (用药)** | 药名 · 剂量 · 剂型 · 用药时间 · 备注 · 打卡记录 | 服药提醒 · 趋势 |
| **日常追踪** | 睡眠 / 体重 / 社交节律 / 应激事件 / 治疗 / 焦虑急躁 6 子模块 | 自我观察 |
| **烦恼闭环** | 烦恼主题 · 关联情绪日记 · 状态(open/resolved) | 闭环管理 |
| **危机热线** | 5 地区 + 国际(见第三条 · 危机热线清单) | 紧急联络 |
| **数据管理** | JSON v6 多版本导出 / 导入 · 一键本地清空 | 备份与删除 |

### 1.3 重要事实

- **本 App 所有数据完全本地存储** (SQLCipher AES-256 + flutter_secure_storage 设备绑定)
- **本 App 后台 0 网络 IO** (`check_no_network_io.py` 守门员强制)
- **本 App 完全免费, 永久免费, 0 内购 / 0 订阅 / 0 收费计划** (v1.0.0+147 定版)
- **本 App 0 第三方追踪 / 0 广告 / 0 分析**
- **本 App 非医疗器械,不涉及任何临床决策**

## 二、服务范围

### 2.1 本 App 提供

- 情绪日记 / 树洞 / 自我测评 / 自我照护 / 日常追踪 / 烦恼闭环的数据本地存储
- 数据可随时导出 (JSON v6 多版本) 或全部清空

- 任何云端推送通知 / 个性化推荐 / AI 智能洞察(若未来上线,会提前更新本协议 + 单独同意)
