# 敏感个人信息处理同意书

> **版本**: v1.0.0 (R128e 医疗声称降级 + 合规过审收尾定版)
> **生效日期**: 2026-08-18
> **法律依据**: 《中华人民共和国个人信息保护法》(PIPL) 第 28-29 条关于"敏感个人信息"的规定 · 《数据出境安全评估办法》 · 《App 违法违规收集使用个人信息行为认定方法》

本同意书 **MoodDiary 心情日记** (以下简称"本 App")专门就敏感个人信息处理取得您的单独同意。

---

## 一、什么是敏感个人信息

依据《个人信息保护法》§28,**敏感个人信息**是一旦泄露或者非法使用,**容易导致自然人的人格尊严受到侵害或者人身、财产安全受到危害**的个人信息,包括:

- 医疗健康信息
- 生物识别信息
- 宗教信仰
- 特定身份
- 金融账户
- 行踪轨迹
- 14 周岁以下未成年人的信息
- 不满 14 周岁未成年人的个人信息

本 App 不处理生物识别 / 宗教信仰 / 特定身份 / 金融账户 / 行踪轨迹 / 未成年人信息等敏感类目。**本 App 仅处理"医疗健康" 与"私密倾诉"两类敏感个人信息**,详见第二条。

---

## 二、本 App 处理的敏感个人信息

依据 PIPL §28、§29 与《App 违法违规收集使用个人信息行为认定方法》第 5 条,本 App 处理的敏感个人信息如下:

### 2.1 情绪健康信息(原"医疗健康" → 改为"情绪健康",R128e 医疗声称降级)

| 字段 | 收集目的 | 处理方式 | 存储位置 |
|---|---|---|---|
| **日记 4 维评分** (心情 / 能量 / 睡眠 / 焦虑) | 自我观察 + 趋势分析 | 本地计算 + 本地查询 | 本地加密数据库 |
| **CBT 思维记录** (3/5/7 栏 Beck 标准) | 自我反思 | 本地存储 | 本地加密数据库 |
| **状态短语** (17 种预设如"有点难过") | 情绪记录 | 本地写入 | 本地加密数据库 |
| **影响因素标签** (预设 8 类) | 自我观察 | 本地写入 | 本地加密数据库 |
| **语音附件** (日记语音备注) | 用户主动录制 | 本地录音 + AES-256 加密 | 本地加密文件 |
| **文字备注** | 自我观察 | 本地写入 | 本地加密数据库 |

### 2.2 自我测评结果

| 字段 | 收集目的 | 处理方式 | 存储位置 |
|---|---|---|---|
| **10 个量表答案** (ISI / PSS / WHODAS / DSM-5 Level2 × 4 / ASRM) | 自我观察 | 本地评分 + 本地查询 | 本地加密数据库 |
| **总分** (R128e 起不再显示严重度解读) | 自我观察 | 本地计算 | 本地加密数据库 |
| **答题时间戳** | 历史趋势 | 本地记录 | 本地加密数据库 |

> R128e 医疗声称降级: 自我测评结果**仅显示总分**,**不**显示"轻度 / 中度 / 重度"等临床分级诊断。**不**基于分数自动弹"危机干预"窗口(此为诊断行为)。危机热线入口保留在「设置 → 法律与隐私」页面,用户主动使用。

### 2.3 自我照护用药信息(原"医疗健康用药" → 改为"自我照护用药",R128e 降级)

| 字段 | 收集目的 | 处理方式 | 存储位置 |
|---|---|---|---|
| **药名** (用户主动填写) | 用药提醒 · 趋势 | 本地写入 | 本地加密数据库 |
| **剂量** | 用药提醒 | 本地解析 | 本地加密数据库 |
| **剂型** (片剂 / 胶囊 / 液体) | 列表展示 | 本地写入 | 本地加密数据库 |
| **用药时间** | 提醒触发 | 本地存储 | 本地加密数据库 |
| **备注** | 自我记录 | 本地写入 | 本地加密数据库 |
| **打卡时间戳** | 连续打卡统计 | 本地计算 | 本地加密数据库 |

> "自我照护用药"定位: 用户**主动记录**自己的服药时间用于自我提醒,**不构成医嘱**,**不**替代医师处方。详见《免责声明》。

### 2.4 日常追踪(归类为一般敏感度看场景)

| 子模块 | 字段 | 收集目的 | 存储位置 |
|---|---|---|---|
| 睡眠 | 睡眠时长 / 质量 / 备注 | 自我观察 | 本地加密数据库 |
| 体重 | 体重(kg) | 自我观察 | 本地加密数据库 |
| 社交节律 | 活动 / 时间 | 自我观察 | 本地加密数据库 |
| 应激事件 | 事件描述 / 强度 | 自我观察 | 本地加密数据库 |
| 治疗 | 治疗类型 / 日期 / 来源 | 自我观察 | 本地加密数据库 |
| 焦虑急躁 | 强度 / 频率 | 自我观察 | 本地加密数据库 |

> 日常追踪**不**涉及医疗健康诊断, 仅作为个人自我观察工具。

### 2.5 树洞倾诉内容(最高敏感)

| 字段 | 收集目的 | 处理方式 | 存储位置 |
|---|---|---|---|
| **树洞文字** | 用户主动记录 | 本地写入 + AES-256 字段级加密 | 本地加密数据库 |
| **树洞录音** | 用户主动录制 | 本地录音 + AES-256 文件级加密 | 本地加密文件 |
| **标签** (3 大类 8 子项) | 分类检索 | 本地写入 | 本地加密数据库 |

> **树洞内容是本 App 最高敏感的数据**,承诺如下:
> - 树洞内容**绝不**进入趋势分析 / 自我测评 / 通知 / 任何统计
> - 树洞内容**绝不**离开用户设备
> - 树洞文字 / 录音均**不**包含在隐私政策声明的"导出 JSON"中,仅 metadata 保留(因为录音文件名无法跨设备复用)
> - 树洞数据导入后,会作为新条目添加(不会覆盖现有树洞)
> - 树洞含录音附件的条目,在用户主动删除时**整条删除**(文字 + 录音 + 标签同步)

### 2.6 烦恼闭环内容

| 字段 | 收集目的 | 存储位置 |
|---|---|---|
| 烦恼主题 | 闭环管理 | 本地加密数据库 |
| 关联情绪日记条目 | 关联 | 本地加密数据库 |
| 状态(open / resolved) | 闭环 | 本地加密数据库 |
| "忆往昔"归档 | 闭环 | 本地加密数据库 |

## 三、处理目的与方式

### 3.1 处理目的

- **单一目的**: 仅用于您的个人自我观察 + 自我记录 + 趋势回顾,**不**用于任何医学研究 / 算法训练 / 第三方共享 / 商业分析
- **不用于**: 任何形式的诊断、治疗、个案咨询、临床决策

### 3.2 处理方式

- **本地计算**: 用药提醒、趋势统计、烦恼时间线、连续打卡等均在本地数据库计算
- **本地存储**: 13 个表 + 树洞录音/语音附件,均加密存储
- **本地加密**: SQLCipher AES-256 + 字段级 AES-256 + flutter_secure_storage 密钥管理
- **本地通知**: 走系统级本地通知 API,不推送服务器
- **本地导出**: 主动导出 JSON,通过用户选择的目标位置保存
- **本地删除**: 主动删除 / 卸载 App,所有本地数据立即清除

### 3.3 录音与语音识别

- 树洞录音 / 心情语音附件,**仅在用户主动录音时启动设备麦克风**
- 录音完成后立即加密本地存储,不向任何云端服务器上传
- `speech_to_text` 库在 iOS 走 Apple on-device / iCloud STT,Android 走 Google on-device / cloud STT,Web 走 Chrome Web Speech API
- **App 本身不代理 STT 请求到自有云端**

## 四、您的明确同意

依据 PIPL,处理敏感个人信息**必须取得您的单独同意**,而不能"勾选总协议即视为全部同意"。

因此本 App 单独设置此同意书。您需要在 setup 引导中**主动勾选**(默认不勾选)才能使用本 App。

### 4.1 单独同意的层级

本 App 处理 3 类敏感信息(情绪健康 / 自我照护 / 树洞),采用**分层同意**而非统一同意:

| 类别 | 处理依据 | 撤回后效果 |
|---|---|---|
| **必需功能** | 情绪日记 / 自我测评 / 自我照护 / 日常追踪 / 烦恼闭环 / 危机热线 | setup 引导必勾, **不**提供撤回(撤回整个同意书 = 卸载 App) |
| **可选功能·树洞** | 私密倾诉内容 | 撤回后 VentRepository.add 拒绝写入,新树洞条目不能保存 |
| **可选功能·趋势分析** | 跨记录趋势统计 | 撤回后 TrendPage 显示"已撤回"占位 |

### 4.2 同意方式

- **setup 引导**: 3 项同意(用户协议 / 隐私政策 / 敏感数据同意书) 单独勾选,**默认不勾选**
- **同意时刻 + 协议版本号**写入本地数据库(`userAgreementVersion` / `privacyPolicyVersion` / `sensitiveDataConsentAt`),可审计,不可篡改
- **撤回同意**:App 内「设置 → 法律与隐私」页面随时撤回

### 4.3 撤回同意的实现

- 撤回「树洞」: VentRepository.add 拒绝写入,新树洞条目不能保存
- 撤回「趋势分析」: TrendPage 显示"已撤回"占位
- 撤回时刻记录到本地供审计
- 撤回后**数据不删除** (用户可重新开启)
- 完全撤回: 卸载 App = 完全删除所有本地数据

## 五、不提供敏感信息的后果

| 拒绝提供 | 影响 |
|---|---|
| **不提供情绪日记评分** | 趋势页无法生成趋势线, 4 维度状态不可视 |
| **不提供 CBT 思维记录** | 思维记录功能不可用,但其他功能不受影响 |
| **不提供自我测评答案** | 测评结果不保存, 仅即时显示 |
| **不提供自我照护用药信息** | 用药提醒只能记录时间,无法记录具体药物 |
| **不提供树洞文字** | 树洞倾诉功能不可用,其他功能不受影响 |
| **不提供树洞录音** | 树洞录音按钮不可用, 文字树洞仍可用 |
| **不提供日常追踪** | 该子模块功能不可用, 其他子模块不受影响 |

**不提供任何敏感信息时,App 仍可作为基本的情绪记录器使用。**

## 六、处理期限

- **用户主动删除的数据**: 删除瞬间清除
- **用户卸载 App**: 所有本地数据立即清除(包括全部同意记录)
- **长期保留**: 用户可永久保留数据,只要 App 还在使用
- **我们无法在服务器保留您的数据(因为我们没有服务器)**

## 七、您的特别权利(敏感信息)

依据 PIPL §44-50,针对敏感个人信息您享有加强保护:

| 权利 | 行使方式 |
|---|---|
| **单独同意** | setup 引导单独勾选本同意书 |
| **单独撤回** | App 内「设置 → 法律与隐私」撤回"树洞 / 趋势分析"可选同意 |
| **单独删除** | App 内删除单条 / 全部敏感数据 |
| **单独导出** | App 内「设置 → 数据管理」导出 JSON(单独或全部) |
| **处理目的拒绝** | 拒绝后该功能不可用,其他功能不受影响 |
| **强制删除** | 卸载 App = 强制删除 + 删除同意记录 |

## 九、信息共享(重申)

本 App **不向任何第三方提供您的敏感个人信息**。

仅在以下情形下数据可能离开设备(均经用户主动):

1. **您主动导出 JSON 备份** — 数据保存在您选择的位置,当次导出
2. **您主动分享** — 通过系统分享面板(用户选择目标 App)
3. **法律法规要求** — 公安/检察机关依法调取(目前 App 无云端,无法响应)

如未来接入云端服务(如多设备同步 / AI 智能洞察),将:

1. 走 PIPL §38 标准合同或安全评估
2. 更新本同意书 + 重新取得单独同意
3. 单独说明跨境传输场景
