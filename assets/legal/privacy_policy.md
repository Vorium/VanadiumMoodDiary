## 二、本 App 收集哪些信息

### 2.1 收集原则

依据《个人信息保护法》§6、§7、§9、§13、§14:
- 收集个人信息应**具有明确合理目的**,且与处理目的直接相关,采取对个人权益影响最小的方式
- 收集敏感个人信息应取得**单独同意**
- 不得过度收集

本 App **100% 本地存储**,**0 云端 / 0 服务器 / 0 第三方 SDK 上传**。以下信息仅写入您设备本地加密数据库,不会离开设备。

### 2.2 收集清单

| 类别 | 字段 | 收集目的 | 存储位置 | 敏感度 |
|---|---|---|---|---|
| **用户标识** | 用户昵称(可选) | 个性化通知与报告 | 本地加密数据库 (SQLCipher AES-256) | 一般 |
| **情绪日记** | 4 维评分(心情/能量/睡眠/焦虑) · 影响因素标签 · 状态短语 · CBT 思维记录 · 录音附件 · 文字备注 | 自我观察 + 趋势分析 + 自我反思 | 本地加密数据库 + 录音文件(本地 AES-256 加密) | 一般 |
| **树洞倾诉** | 文字 · 录音 · 标签(归属学习/工作/情感/身心健康 3 大类 8 子标签) | 私密记录 | **本地加密**: 文字字段级 AES-256 · 录音文件 AES-256 (密钥设备绑定) | **敏感** |
| **自我测评** | 10 个量表(ISI/PSS/WHODAS/DSM-5 Level2 × 4/ASRM) · 答案 · 总分 · 答题时间 | 自我观察 | 本地加密数据库 | 一般 |
| **自我照护 (用药)** | 药名 · 剂量 · 剂型 · 用药时间 · 备注 · 打卡记录 | 用药提醒 · 趋势 | 本地加密数据库 | **敏感** |
| **日常追踪** | 睡眠 / 体重 / 社交节律 / 应激事件 / 治疗 / 焦虑急躁 6 子模块 | 自我观察 | 本地加密数据库 | 一般 |
| **烦恼闭环** | 烦恼主题 · 关联情绪日记 · 状态(open/resolved) | 闭环管理 | 本地加密数据库 | 一般 |

| **设备信息** | 设备型号 · 操作系统版本 | 仅本地判断通知 API 兼容性(如 `exactAllowWhileIdle`) | **不存储 / 不上传** | 一般 |
| **日志** | App 异常栈 / 崩溃日志 | 仅本地 `swallowError` 缓存,用户主动反馈时附 | 加密本地 + 不上传 | 一般 |

### 2.3 本 App **不**收集

依据 PIPL §6,我们主动声明以下信息**绝不收集**:

- 位置 / GPS / 指纹 / 人脸识别
- 通讯录 · 联系人列表(对应业务已删除,无此领域)
- 相册 / 照片 / 视频
- 设备 ID · IDFA · 广告 ID
- 后台持续追踪 / 行为画像
- 支付 / 订单 / 银行账户
- 任何分析 / 追踪 SDK 行为
- 任何第三方共享数据

### 2.4 App 后台零网络 IO

可选架构层面证明: 本 App `lib/core/data/services/` 中**无任何 HTTP 客户端依赖**,除用户主动触发的导出 / 分享 / 危机热线拨打 / 系统通知 4 类用户主动行为外,App 后台**完全无网络请求**。项目设 `check_no_network_io.py` 守门员在 CI 强制拦截 release 模式新增网络调用。

## 三、个人信息存储与保护

### 3.1 存储位置

- **本地 SQLite 数据库** (Drift 2.20.3) — 13 张表 (CheckIns / UserProfiles / ReportHistories / MoodEntries / VentEntries / SleepEntries / SocialRhythmEntries / StressEvents / TreatmentEntries / WeightEntries / AnxietyAgitationEntries / Medications / WorryThreads)
- 文件级存储: 树洞录音 / 心情语音附件 / 数据导出 JSON 文件 — App 私有目录 (`/data/data/<package>/files/`)
- 同意版本留痕: `userAgreementVersion` / `privacyPolicyVersion` / `sensitiveDataConsentAt` — 写入数据库,可本地审计

### 3.2 加密机制

| 层 | 算法 | 密钥管理 |
|---|---|---|
| 数据库整体 | **SQLCipher AES-256** | `SecureRandom` 生成,绑定设备 |
| 树洞文字字段 | **AES-256 字段级加密** | 独立密钥,flyer SecureStorage 管理 |
| 树洞录音 / 心情语音 | **AES-256 文件级加密** | 独立密钥,IV 每次随机 |
| 共享偏好 (settings) | flutter_secure_storage (iOS Keychain / Android Keystore) | 设备绑定 |

### 3.3 加密强度

- 设备 root + 拿到 DB 加密 key + 拿到 SecureStorage key 三者凑齐才能解密
- 单层密钥泄露**无法**单独解密数据
- 量子计算安全: 当前 AES-256 + 256-bit 密钥在量子算法下仍有 128-bit 等效安全,是 NIST 后量子标准的前置过渡方案

### 3.4 监听与备份

- App 退出即停止所有任务, 录音写入完成立即加密落盘
- 录音写入完成即关闭 I/O, 防意外截断
- `markAppDocsExcludedFromBackup` 已调用,iCloud Backup / Google Drive Backup 自动排除 App 文档
- 卸载 App 后所有本地数据立即清除,无任何云端残留

## 六、用户权利与行使方式

依据《个人信息保护法》§44-50,您享有以下权利:

| 权利 | 行使方式 |
|---|---|
| **知情权** | 阅读本政策 |
| **决定权** | 选择是否提供某些信息(药名 / 昵称可填"匿名") |
| **查询权** | App 内查看所有打卡 / 评估 / 树洞 / 用药记录 |
| **更正权** | App 内修改 / 删除任何记录 |
| **删除权** | App 内删除单条 / 全部数据;卸载 App 立即清除所有本地数据 |
| **撤回同意** | App 内「设置 → 法律与隐私」页面随时撤回"树洞 / 趋势分析"2 项可选功能;撤回后该功能立即停用,数据保留可重新开启 |
| **注销权** | 卸载 App = 完全注销,所有本地数据立即清除 |
| **解释权** | 通过本政策 §9 联系方式要求解释 |

### 6.1 撤回同意的实现

- **ConsentGate 集中器统一执行** (`lib/core/data/services/consent_preference_store.dart`)
- 撤回「树洞」时,VentRepository.add 拒绝写入;新树洞条目不能保存
- 撤回「趋势分析」时,TrendPage 显示"已撤回"占位
- 撤回时刻记录到本地供审计
- 撤回后**数据不删除** (用户可重新开启)

### 6.2 主动删除与注销

- 单条删除: App 内点击任意记录右上角删除按钮
- 全部删除:「设置 → 数据管理 → 清空全部数据」(二次确认 + 5 秒倒计时)
- 卸载 App:等同完全注销,所有本地数据立即清除

## 七、跨境数据传输

依据《个人信息保护法》§38、§39、§40 与《数据出境安全评估办法》,个人信息处理者向境外提供个人信息需满足以下任一条件:

1. 通过国家网信部门组织的安全评估
2. 经专业机构进行个人信息保护认证
3. 按照国家网信部门制定的标准合同与境外接收方订立协议
4. 法律、行政法规或者国家网信部门规定的其他条件

**现状**:

- 本 App **无云端服务器**,数据库全部存放在用户设备本地
- 用户的情绪日记 / 测评 / 树洞 / 用药数据**永不上传**到任何服务器
- 本 App 不向任何第三方发送跨境通知、短信或邮件
- 危机热线拨打走用户设备本地拨号,**App 不发起跨境通信**
- 语音识别走系统平台 STT(iOS Apple / Android Google / Web Chrome),App 不代理
- **当前版本无任何跨境 PII 传输实际场景**

如未来接入云端服务(如多设备同步、AI 智能洞察),将:
1. 走 PIPL §38 第 3 项标准合同或第 1 项安全评估
2. 提前在本政策更新 + App 内通知
3. 重新索取用户同意

## 九、未成年人保护

依据《未成年人保护法》§44 与《个人信息保护法》§31,网络产品和服务对未成年人有特殊保护义务。

**本 App 的未成年人保护措施:**

- 本 App 设计面向**成年人(18 周岁以上)**使用,**不建议 14 周岁以下儿童单独使用**(精神心理类敏感数据,需监护人共同阅读本政策并辅助使用)
- 14-18 周岁用户**需监护人代为同意**,App 在 setup 引导中要求用户勾选严正声明:"本人郑重承诺:我已年满 18 周岁。如本人为 14-18 周岁,本人保证已取得监护人代为同意,并愿意承担虚假陈述的一切法律后果。"
- App 不会主动收集任何 14 周岁以下用户的敏感个人信息
- 如发现 14 周岁以下用户误用,监护人可通过 App 内「设置 → 法律与隐私」页面发起数据删除请求(响应时间 7 个工作日内)
- 本 App 不会向未成年人推送任何营销内容或广告
