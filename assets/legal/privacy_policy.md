# 隐私政策

> **本政策是 v0.18 草稿,未经律师过审,上 store 前必须由专业律师审阅并更新。**
> 依据:《中华人民共和国个人信息保护法》(PIPL)、《App 违法违规收集使用个人信息行为认定方法》
> 最后更新:2026-07-18

## 1. 我们收集哪些信息

| 信息类别 | 具体字段 | 收集目的 | 存储位置 |
|---|---|---|---|
| 用户标识 | 用户姓名 | 在通知 / 报告中"我是 XXX" | 本地加密数据库 (SQLCipher) |
| 紧急联系人 | 姓名 + 手机号 | 失联通知用 | 本地加密数据库 |
| 健康数据 | 药名、剂量、打卡时间、PHQ-9 / GAD-7 评分 | 服药追踪、趋势分析 | 本地加密数据库 |
| 私密倾诉 | 文字 / 录音(树洞) | 用户主动记录 | **本地**(音频文件当前**未加密**,v1.0+ 加密,见第 5 条) |
| 设备信息 | 设备型号、操作系统版本 | 通知 / 兼容性 | 不收集 |

**我们不收集:**位置、通讯录、相册、相机(录音除外)、设备 ID、广告 ID。

## 2. 信息的存储与保护

- 所有数据**仅存在用户设备本地**,**不上传任何云端**
- 数据库使用 **SQLCipher AES-256** 加密(密钥由设备 SecureRandom 生成,绑定设备)
- 数据库密钥**不离开设备**,不存储在我们或任何第三方服务器
- 录音文件存放在 App 私有目录 (`/data/data/<package>/files/`)。**v0.18 之前,录音文件本身未加密(只有 DB 加密);v1.0+ 将对录音也加密。**

## 3. 信息的共享

**我们不共享任何用户数据给第三方**,除非:

- 用户**主动**使用"导出 JSON 备份"功能(数据保存在用户剪贴板或用户指定位置)
- 用户**主动**使用"分享"功能(数据通过用户选择的 App 分享)
- 法律法规要求(如公安 / 检察机关依法调取)

**失联通知触发时**,我们会将下列信息发送给用户**预设**的紧急联系人:

- 用户姓名
- 距上次打卡的天数
- 一条预设的关怀短信模板

**我们不主动向紧急联系人以外的任何人发送信息。**

## 4. 用户的权利

依据 PIPL,您享有以下权利:

| 权利 | 行使方式 |
|---|---|
| 知情权 | 阅读本政策 |
| 决定权 | 选择是否提供某些信息(药名可填"匿名") |
| 查询权 | 在 App 内查看所有打卡 / 评估 / 树洞记录 |
| 更正权 | 在 App 内修改 / 删除任何记录 |
| 删除权 | 在 App 内删除单条 / 全部数据;卸载 App 立即清除所有本地数据 |
| 撤回同意 | 在设置页随时关闭"失联通知"等可选功能 |
| 注销权 | 卸载 App = 完全注销,所有本地数据立即清除 |

## 5. 录音加密(v1.0+ 计划)

**v0.18 已知问题:** 录音文件本身未加密,只有 DB 加密。设备 root 后可直接读取录音文件。
**v1.0+ 改进:** 录音将使用 AES-256 加密,密钥由用户设置的 passcode 通过 PBKDF2 派生。
**过渡方案:** 用户可定期导出 JSON 备份,删除 App 内录音,需要时通过备份文件查看文字(但录音无法恢复)。

## 6. Cookie 与追踪

本 App **不使用任何 Cookie、追踪 SDK、广告 SDK**。

## 7. 第三方依赖

本 App 使用的第三方库(均不收集用户数据):

- `flutter_secure_storage` — 密钥存储(iOS Keychain / Android Keystore)
- `sqlcipher_flutter_libs` — 数据库加密
- `flutter_local_notifications` — 本地通知
- `audioplayers` / `record` — 录音 / 播放
- `go_router` / `riverpod` / `drift` — 框架

完整列表见 `pubspec.yaml`。
