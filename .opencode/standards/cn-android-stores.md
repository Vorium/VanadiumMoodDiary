# 国内安卓市场规范要点 (cn-android-stores.md)

> 来源: 工信部备案规定 + 华为/小米/OPPO/vivo 开发者中心公开规范 (2026-08-16 基于知识库生成) `[来源: 知识库，待人工核验]`
> 适用: 华为 AppGallery / 小米应用商店 / OPPO 软件商店 / vivo 应用商店 / 应用宝

## 前置资质 (硬门槛)
- **ICP 备案** (2023-09 起国内分发强制): 应用主办者备案 — App 备案编号须填各家商店后台; 域名 ICP 备案是隐私政策 URL 前置
- **软著 (计算机软件著作权)**: 华为/小米/应用宝要求 (OPPO/vivo 部分类别要求)
- 医疗健康类: 国内"医疗器械"分类需《医疗器械注册证》— **本项目定位自我关怀工具 (非医疗器械), 商店分类选"健康工具"而非"医疗", 文案避免诊断/治疗词汇** (已有 "NOT a medical device" 思路但国内文案需更谨慎: "仅供参考, 不构成医疗建议")
- 版号: 仅游戏类需要, 不适用

## 各家差异要点
| 商店 | 特有要求 |
|---|---|
| 华为 AppGallery | 软著 + ICP + 隐私政策 URL; 审核较严, 心理类需免责声明 |
| 小米 | 软著 + 隐私政策; 自检报告 (权限/隐私行为清单) |
| OPPO | 软著 + 隐私政策; 绿色应用公约 (权限最小化) |
| vivo | 隐私政策 + 权限说明 |
| 应用宝 | 软著 + ICP + 资质最严; 健康类可能要求相关资质 |

## 权限与隐私 (工信部规范)
- 权限最小化: 国内对 RECORD_AUDIO 审查严 — 首次使用时动态申请 + 用途说明 (已落地)
- 个人信息保护法 (PIPL): 单独同意 + 撤回通道 (已落地 legal consent 体系)
- 禁止"一揽子同意" / 拒绝后不得反复弹窗
- 个人信息本地化: 全本地存储 = 合规亮点 (无出境问题)
