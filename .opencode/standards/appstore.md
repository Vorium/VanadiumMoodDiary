# App Store 审核规范要点 (appstore.md)

> 来源: Apple App Store Review Guidelines (2026-08-16 webfetch developer.apple.com/app-store/review/guidelines/) — 部分条款为长期稳定版摘录, 提交前建议复核官网。
> 适用项目: chroniccare (Flutter 精神心理自我关怀 App, iOS 平台, 零云端本地加密)

## 审核前自查 (Before You Submit)
- 测试崩溃与 bug / metadata 完整准确 / 联系信息可送达
- 非明显功能在 review notes 详细说明
- 后端服务审核期间在线 (本项目零云端 → notes 说明全本地)

## 1. Safety
- 1.1 不良内容: 1.1.6 虚假信息/假功能会拒
- 1.2 UGC (树洞是私密日记非社交 → 无需举报机制, 但 notes 说明"内容仅本地, 无社区")
- 1.4 身体伤害: **1.4.1 医疗类 App 更高审查** — 必须披露数据与方法论、提醒用户咨询医生; 本项目 6 量表自评 + 危机热线 → 必须有免责声明 (已有 "NOT a medical device") + 5.1.3 健康类问卷
- 1.4.2 剂量计算器: 本项目用药记录**不做剂量计算** — 若 UI 有换算必须来自药厂/医院 (注意: 用药提醒时段计算不属于剂量计算)
- 1.5 开发者信息: Support URL 必须可达
- 1.6 数据安全: 用户数据处理措施 (本地 SQLCipher 加密 = 合规亮点, notes 说明)

## 2. Performance
- 2.1 完整性: 占位文本/空网站/临时内容提交前必须清除 (2.1 是 R112 时代最大拒因类别)
- 2.3 元数据准确: 2.3.1 隐藏/休眠/未文档化功能拒 (FeatureFlag 关掉的 PHQ-9/GAD-7 不得在文案宣传); 2.3.3 截图须展示 App 实际使用场景
- 2.3.7 名称 ≤30 字符, metadata 不含价格/商标词
- 2.5.1 只用公开 API; HealthKit 未集成就不得声明
- 2.5.5 IPv6 (纯本地 App 无网络请求, notes 说明)

## 3. Business
- 3.1 支付: 无 IAP (1.0.0 已删) — notes 说明永久免费
- 3.2 其他业务: 无订阅/无广告

## 4. Design (要点)
- 4.1 抄袭会被拒; 4.2 最低功能 (2017 垃圾应用规则: 简单问卷套壳风险 → 本项目有完整功能链, 低风险)
- 4.3 马甲应用; 4.4 扩展与插件的功能必须与主体相关 (通知扩展无)

## 5. Legal
- **5.1 隐私**: 5.1.1(i) 收集数据需隐私政策 URL + 明确同意 (PIPL §13/§14 单独同意已落地); 隐私政策必须与实际收集一致 (本地 App 收集 0 → 政策写明)
- 5.1.1(v) 账号需提供删除账号入口 (无账号)
- **5.1.3 健康/健康研究 App 抽审问卷**: 量表自评 + 危机热线 → 必填问卷 (草稿在 docs/SUBMISSION_INFO.md §2.5.3)
- 5.1.4 儿童: 4+ 年龄分级; 不面向儿童则无特殊要求
- 5.2 知识产权: 量表名称 (PHQ-9/GAD-7/ASRM 等) — PHQ-9/GAD-7 有版权 (Pfizer), 目前 flag 隐藏 → 上线时需确认授权或移除
- 5.3 博彩/5.4 VPN/5.5 计算服务: 不适用
- 5.6 开发者行为准则
