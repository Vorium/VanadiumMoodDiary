# v0.17 动效集中器抽离决策（v0.24 round 48 P3-10 归档）

> **背景**：v0.17 round 14 (P1-1) 把动效集中到 `lib/presentation/widgets/animations/` 目录
> **v0.24 round 48 续**：P1-2 把 `CelebrationOverlay` 抽到 `animations/celebration_bounce.dart` 作为第 4 个集中 widget
> **作者**：Mavis orchestrator + emil 决策框架

---

## 抽离动机

**v0.17 之前**：项目内 30+ 处 widget 各自 `AnimatedContainer` / `AnimatedOpacity` / `AnimatedSwitcher`，每个写自己的 duration/curve。问题：
1. duration 散落（200/300/500/800/1000/1500 ms 都有）
2. curve 散落（`Curves.easeInOut` / `easeOutCubic` / `easeOutBack` 都有）
3. reduce-motion 处理散落（部分 widget 用 `MediaQuery.of(context).disableAnimations`，部分没有）
4. emil 决策框架无法应用（"频度" 概念没抽象）

**v0.17 抽离**：建 `lib/presentation/widgets/animations/` 目录，3 个集中 widget：
- `FadeIn` — opacity + 可选 scale
- `SlideUp` — translate Y + fade
- `PageTransitionSwitcher` — AnimatedSwitcher 包装

**v0.24 round 48 P1-2 续**：加第 4 个：
- `CelebrationBounce` — scale 0→1.2→1.0 + opacity 5 段 TweenSequence

---

## 4 个集中 widget 矩阵

| Widget | 频度（emil）| 适用场景 | duration | curve |
|---|---|---|---|---|
| `FadeIn` | occasional | list item 出现 / 弹层背景 | `durNormal` (300ms) | `curveStandard` |
| `SlideUp` | occasional | bottom sheet / dialog | `durNormal` (300ms) | `curveStandard` |
| `PageTransitionSwitcher` | rare | 页面切换 | `durFast` (200ms) | `curveStandard` |
| `CelebrationBounce` | rare | 打卡庆祝 / 解锁成就 | `durSlow` (500ms) | `curveBackOut` + `curveDelight` |

**emil 原则**：集中 widget 内部用 token（`AppTokens.dur*` / `AppTokens.curve*`），**不**硬编码 ms/curve。

---

## 决策

1. **新动效** 必须加到 `animations/` 目录，**不**在 widget 内自研 TweenSequence
2. **集中 widget** 接受 `duration` / `curve` 可选参数（默认走 `Motion.duration/curve` reduce-motion 包装）
3. **`Motion.duration(context, base)` / `Motion.curve(context, base)`** 是 reduce-motion 包装唯一入口
4. **caller 改 widget 不要重新实现** — 直接 import `animations/animations.dart` 用集中 widget

---

## 已知反模式（应避免）

- ❌ widget 内 `AnimatedContainer(duration: AppTokens.durFast, curve: ...)` — 缺 reduce-motion 包装
- ❌ widget 内自研 `TweenSequence` — 复用度 0
- ❌ 直接用 `Curves.easeInOut` 不用 `Motion.curve` — 缺 reduce-motion 包装
- ❌ 多个 `AnimatedBuilder` 嵌套 — 性能 + 维护成本
