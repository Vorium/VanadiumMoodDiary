## P3-1/2: `@media (hover: hover)` 等价物 + Card/ListTile hover 动效 gate

**skip 原因**：Flutter M3 `InkWell` 已经监听 `PointerHoverEvent`（pointer device mouse / trackpad），自动渲染 hover ripple + elevation。无需额外 gate。

**v0.25+ 路径**：无（已 M3 内置）。如果未来要"hover 抑制动画"，参考 web 用 `MediaQuery.maybeOf(context)?.accessibleNavigation` 或 `defaultTargetPlatform`。

## P3-14: 农历日期支持

**skip 原因**：
- 用户群体**主要在大陆 + 海外华人**，但 App 是"打卡 + 提醒"功能，**日期核心是公历**
- 农历只在**节日提醒**（春节 / 中秋等）有意义 — 已经在 P1-19 sub-agent 计划里
- 全量日期显示农历**会让 UI 变复杂 + 海外用户混淆**

**v0.25+ 路径**：
- 节日识别（春/中秋/国庆/清明/端午/劳动）→ P1-19 sub-agent 已建 data layer
- 集成 reminder_scheduler → **只在节日当天 8AM 推"今天放假，记得吃药"**（不带日期显示）
- 不改 UI 日期显示（保持公历）

---

## P3-15: 中文 markdown lint

**skip 原因**：
- 中文标点 / 全角空格 / 中英混排 的 lint 规则**容易误报**（"vs." 是英文缩写 vs 中文标点）
- 项目 CHANGELOG.md / docs/ 已经人工 review（每次 commit 必有）
- 自动化价值低 + 误报率高

**v0.25+ 路径**：
- 仅在 **CI release-tag** 跑（不阻塞 PR）
- 用 `markdownlint-cli` + 自定义规则：
  - 中英文之间 1 空格
  - 中文标点（全角）vs 英文标点（半角）不混用
  - 但允许 `user_id` / `API` / `Flutter` 等技术词
