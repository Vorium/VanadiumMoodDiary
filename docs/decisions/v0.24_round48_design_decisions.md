## 1. MotionScheme 4 档频度决策（emil 决策框架）

| 频度 | duration | curve | 适用 |
|---|---|---|---|
| 100+/day | `durFast` (200ms) | `curveSubtle` (easeOut) | 打卡、键盘、核心导航 |
| tens/day | `durFast` (200ms) | `curveSubtle` (easeOut) | hover、list item 选中态、ripple |
| occasional | `durNormal` (300ms) | `curveStandard` (easeOutCubic) | modal、drawer、snackbar、状态切换 |
| rare | `durSlow` (500ms) | `curveDelight` (elasticOut) | onboarding 首次、庆祝、解锁成就 |

**关键决策**（v0.24 round 48 emil P1-1）：
- `MotionScheme.subtle` **必须** 用 `curveSubtle`（不是 `curveStandard`）
- 之前 subtle / standard 共用 `curveStandard` → 频度档位虚设（emil "decisions should be nameable"）
- 现在 subtle 体感"几乎察觉不到"（200ms + easeOut），standard 体感"明显但不快"（300ms + easeOutCubic）

## 2. InkWell Material 3 shader 修补决策（历史）

**问题**：Material 3 InkWell 在 widget test 中需要 `shaders/ink_sparkle.frag`，但 `flutter test` 默认 `TestAssetBundle` 不带这个 shader。

**修法**（v0.17 round 8）：
- 从 `$FLUTTER_ROOT/packages/flutter/lib/src/material/shaders/ink_sparkle.frag` 复制到 `assets/shaders/ink_sparkle.frag`
- `pubspec.yaml` `flutter: shaders:` 字段声明

**注意**（v0.17 round 8 经验）：
- Flutter 3.44.5+ shader format 升级 (1→2) 暂时不兼容此 trick
- 当前项目跑 Flutter 3.41.9 → work
- 未来升级 Flutter 前要重新测试，必要时升级 shader 源

## 3. `_streamTimeout` 命名 lint（sp-en P2-14）

**问题**：`no_leading_underscores_for_local_identifiers` lint 警告
- `data_export_service.dart:103` `const _streamTimeout = Duration(seconds: 5);` 触发警告
- `reminder_scheduler.dart:33` 是 instance field → 不触发（下划线 OK）

**修法**：local variable 去下划线，instance field 保留
```dart
// local (v0.24 round 48 改)
const streamTimeout = Duration(seconds: 5);
// instance field (保留)
final Duration _streamTimeout;
```
