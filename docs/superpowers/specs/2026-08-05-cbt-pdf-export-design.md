# CBT Thought Record PDF Export — Spec

> **重建日期**: 2026-08-18 (从代码重建)
> **原始 spec 已删**, 基于 `lib/core/data/services/cbt_thought_record_pdf*.dart` + `cbt_pdf_l10n.dart` 推断

## 1. 背景

CBT (认知行为疗法) 思维记录是 mood entry 的核心 5/7 栏字段。用户完成 CBT 重评后, 需要一份可分享 / 打印给咨询师的 PDF 报告。

## 2. 目标

- 导出 CBT 思维记录 (5/7 栏) 为 PDF
- 三语 i18n (zh / en / zh_Hant)
- 数据层 PDF 生成, 不依赖 BuildContext
- 与用药报告 PDF 一致的 facade + layout 分离

## 3. 实施状态

✅ 已实施。v0.30 round 88 sub-spec 4 闭环。

## 5. CBT 8 字段 (MoodEntries table)

| 字段 | 类型 | 用途 |

| `situation` | TEXT | 情境 |

## 6. PDF 结构 (从代码注释推断)

```
Header
  └── ChronicCare — CBT 思维记录
      Date: <timestamp>
      Mood score (before/after): <原始分/重评分>

Section 1: 情境
  └── <situation>

Section 2: 自动思维
  └── <automaticThought>

Section 3: 证据
  ├── 支持: <evidenceFor>
  └── 反对: <evidenceAgainst>

Section 4: 替代思维
  └── <alternativeThought>

Section 5: 重评分数
  └── 原始: <score> → 重评: <reratedScore>

Section 6: 核心信念 + 行为反应 (7 栏才有)
  ├── 核心信念: <coreBelief>
  └── 行为反应: <behaviorResponse>

Footer
  └── Generated by ChronicCare · <version>
```

## 7. 关键设计决策

- **Facade + Layout 分离**: facade 70 行只负责数据装配 + 调度, layout 负责排版 (与 medication_report_pdf 一致)
- **L10n adapter 模式**: `CbtPdfL10n` interface + `AppLocalizationsCbtPdfL10n` adapter, 让 data 层 PDF 走 i18n 而无需读 BuildContext
- **5/7 栏触发**: `cbtReratedEntriesProvider` 过滤 `MoodEntryEntity.cbtLevel >= 5` 的 entry
- **字体**: PDF 内置 Helvetica (中文字符走 zh-Hant fallback)
- **触发器**: 用户在 mood list 选择 entry → 点击"导出 CBT"按钮 → 调 facade → 生成 PDF → 走系统分享
