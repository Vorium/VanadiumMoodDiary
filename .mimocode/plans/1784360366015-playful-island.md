## 二、底层逐行排查

### 2.1 Bug — 需修复

#### 🔴 BUG-1 — `mood_dialog.dart:130` — 使用外层 context 而非 dialog context

**文件**: `lib/presentation/pages/mood/mood_dialog.dart:130`

```dart
// 第 128-131 行
if (ctx.mounted) {
  ScaffoldMessenger.of(ctx).showSnackBar(
    AppSnackBar.error(context, action: '保存', error: e),  // ← BUG: 应为 ctx
  );
}
```

**问题**: `ScaffoldMessenger.of(ctx)` 用的是 dialog 的 `ctx`，但 `AppSnackBar.error(context, ...)` 用的是外层 widget 的 `context`。在 async gap 之后外层 context 可能已 stale。  
**修复**: 将 `context` 改为 `ctx`。  
**难度**: 极低（一行改动）。  
**优先级**: 高 — 影响用户体验（保存失败时可能 crash）。

#### 🔴 BUG-2 — `reminder_scheduler.dart:167` — `dynamic medication` 参数丢失类型安全

**文件**: `lib/core/data/services/reminder_scheduler.dart:167`

```dart
String _buildSmsBody({
  required String userName,
  required int daysSince,
  required int hoursSince,
  required dynamic medication,  // ← BUG: 应为 MedicationEntity?
})
```

**问题**: 参数类型为 `dynamic`，调用方传入的类型不受编译器检查，可能导致运行时 `NoSuchMethodError`。  
**修复**: 改为 `required MedicationEntity? medication`。  
**难度**: 低 — 需确认所有调用方传入正确类型。  
**优先级**: 中 — 当前运行时未出错，但缺乏类型保护。

#### 🟡 BUG-3 — `assessment_page.dart:163` — 评估保存静默失败，数据丢失

**文件**: `lib/presentation/pages/assessment/assessment_page.dart:163`

```dart
try {
  await ref.read(checkInRepositoryProvider).saveAssessment(...);
} catch (_) {
  // 静默失败——结果仍展示
}
```

**问题**: 用户看到评估结果，但数据未持久化。下次查看历史时数据不存在，用户会困惑。  
**修复**: 至少记录错误日志（`piiSafeLog`），或在 UI 上显示"结果已计算但保存失败"的提示。  
**难度**: 低。  
**优先级**: 中 — 数据完整性问题。

#### 🟡 BUG-4 — `vent_compose_page.dart:17` — presentation 层 import `dart:io`

**文件**: `lib/presentation/pages/vent/vent_compose_page.dart:17`

```dart
import 'dart:io';  // ← 架构违规
```

**问题**: `dart:io`（`File` / `Directory.systemTemp`）直接在 presentation 层使用，违反"dart:io 只在 data/ 下用"的架构规则。  
**修复**: 将 temp file 操作委托给 `VentAudioStorage`（data 层），presentation 只调用 service 方法。  
**难度**: 中等 — 需重构 `_reRecord()` 和 `_toggleRecord()` 中的文件操作。  
**优先级**: 中 — 架构一致性问题。

## 四、总结

**整体评价**: 项目架构质量 **优秀**。4 层分层严格执行，domain 纯度、隐私边界、Provider 抽象模式都是教科书级别。代码经历了 18 轮迭代，历史 bug（DateTime race、resource leak、排序假设、通知 range）均已系统性修复。

**最需要关注的 3 件事**:
1. **trend_page.dart 拆分** — 1428 行是最大的维护负担
2. **encrypt 包迁移** — 停维加密包是长期安全风险
3. **mood_dialog context bug** — 一行改动，影响用户体验
