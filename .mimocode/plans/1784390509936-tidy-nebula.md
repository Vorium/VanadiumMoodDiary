# P0 Fix Plan: N+1 Batch Queries + Cache Misses

## Problem 1: N+1 Full-Table Scans (fetch ALL → filter in Dart)

Multiple services fetch the ENTIRE check-in/medication table, then filter + sort in Dart to find "the latest one". For a 1-year user with 400+ rows, this is wasteful.

**Affected locations:**
- `reminder_scheduler.dart:76` — `watchAll().first` → filter normal → sort → `.first`
- `safety_watch_service.dart:162` — same pattern
- `assessment_reminder_service.dart:141` — `watchAssessments().first` → reduce to find latest
- `home_page.dart:348` — `watchAll().first` for CareEngine
- `home_page.dart:113` — `watchAll().first` to find one medication by ID
- `edit_medication_dialog.dart:121` — `watchAll().first` after save
- `medications_list_widget.dart:207` — same after refill update

**Fix:** Add 3 DB-level methods to `AppDatabase`:
1. `watchLatestNormalCheckIn()` — `WHERE type='normal' ORDER BY timestamp DESC LIMIT 1`
2. `getLatestAssessmentTimestamp()` — `WHERE type IN ('phq9','gad7') ORDER BY timestamp DESC LIMIT 1`
3. `watchNormalCheckIns()` — `WHERE type='normal' ORDER BY timestamp DESC` (for allNormalCheckInsProvider)

Then add matching abstract methods to `CheckInRepository` and implement in `CheckInRepositoryImpl`.

## Problem 2: Cache Misses (redundant DB reads when provider tree already has data)

**Affected locations:**
- `main.dart:160` — Creates SECOND `AppDatabase()` instance (duplicate SQLCipher connection)
- `home_page.dart:348` — `ref.read(checkInRepositoryProvider).watchAll().first` instead of using `allCheckInsProvider`
- `home_page.dart:113` — `ref.read(medicationRepositoryProvider).watchAll().first` instead of `medicationsProvider`
- `edit_medication_dialog.dart:121` — same pattern
- `medications_list_widget.dart:207` — same pattern
- `settings_page.dart:342-344` — 3 sequential `await ref.read(...).future` instead of `Future.wait`

**Fix:**
- `main.dart`: Use provider tree's database instead of creating new instance
- Presentation pages: Use `ref.read(provider).value` or `ref.invalidate(provider)` + read instead of `ref.read(repo).watchAll().first`
- `settings_page.dart`: Wrap in `Future.wait`
