## v4.0 升级踩坑记录

### 教训 1：Mavis 自己写长文档必卡循环

**触发**：本次 v4.0 升级最初尝试 Mavis 主线程直接写（按"executing-planning"风格 + 关键判断 + 实际 模式），陷入"让我开始写 / 思考怎么写 / 重新思考"独白循环 100+ 次。

**解决**：必须 spawn sub-agent 写 + 强制章节完成标记（每个 ## 二级章节完成时输出 `## [标题] 完成`）—— 避免静默卡循环。

**v4.0 升级反映**：§8.3 长文档写作准则写入白皮书，作为永久准则。

### 教训 2：sub-agent 也可能卡循环

**触发**：本次后台 spawn dedupe sub-agent，5 分钟无输出，最终取消 Mavis 主线程接管。

**解决**：sub-agent 写长文档时同样需要章节完成标记 + 禁止 meta-thinking + 输入文件直接列出。

**v4.0 升级反映**：sub-agent prompt 现在加 "每个 ## 二级章节完成时输出 `## [标题] 完成`" 强制标记。
